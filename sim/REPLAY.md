# LOUD: replay of a real launch

Generated by `node sim/replay.mjs`. Do not edit by hand.

## Status: no real data in this repository

**This file contains no replay results, because no real data set could be obtained without an API key.** No numbers were made up to fill the gap.

What was tried (see `sim/replay-data/README.md` for the exact requests and answers):

- GeckoTerminal public API, minute OHLCV: reachable without a key, but it only serves the last 180 days. The first candidate pool tried (HAWK / SOL, created 2024-12-04) is older, and the API answers 401 for it.
- DexPaprika: minute candles and any history beyond 24 hours need an API key.
- DefiLlama coin prices: no history for the tokens tried.
- Public reports on bundled launches inside the last 180 days were found, but none of them both named a token address and documented the sales, so no pool could be matched to a report without guessing.

What exists instead:

- The loader and the replay are written and tested (`sim/replay.mjs`, `sim/replay.test.mjs`). The test uses generated candles that are marked as synthetic and never written to this file.
- The download path was run against the live API for a recent pool and returned valid minute candles. That file is not included, because the pool could not be tied to a public report.

To produce a real replay, pick a launch from the last 180 days whose bundle is described in a public report that names the token, then run:

```
node sim/replay.mjs --fetch --network solana --pool <pool address> --hours 6 --label "<name>" --bundled-bps <bps> --wallets <n> --doc-url <report url>
node sim/replay.mjs
```

## What the replay will and will not show

- Real: the minute candles (open, high, low, close, USD volume), the total supply, and the bundle share and wallet count quoted from the public report.
- Model: candles do not say who traded. A minute that closes below its open is counted as selling, any other minute as buying. Selling is attributed to the bundle until the documented bundle share is used up, then to other holders. This overstates how early the bundle sold if other holders sold first.
- Model: only the bundle selling is replayed, as shares of supply, into a pool with the SPEC standard preset (100 virtual NEAR, cap 0.5% per 60 minutes, notice 30 minutes) that holds 300 NEAR of outside liquidity. Buying and other selling are not replayed, so the replay produces no price.
- Model: under LOUD the bundle shouts when it first wants to sell, so the first unit leaves one notice period later, and the cap applies from then on.
- Model: a rule can sell less than the bundle wanted even without a limit, when the model pool runs out of NEAR to pay.
- The replay answers one question: with the same selling pressure, how much of the bundle could have left in the first minutes and hours under each rule. It does not say what the real price would have been.
